# Minigame 1
## Devlog
I would describe the relationship between Components, GameObjects, and Scene likes a movie set. The scene would be the entirety of the movie set where everything takes place, while the GameObjects are the different actors and props on the set. The Components are the different roles and abilities that would give each GameObject (or in this case, the actors) a purpose. For example, a character GameObject would have components that allow it to move and interact with other objects. Together, GameObjects and their components make up the scene and allow the game to function as a whole.
